# 🎓 Moodle AI Quiz Generator Plugin (`local_aiquizgen`)

افزونه پیشرفته، جامع و دانشگاهی آزمون‌ساز مودل متصل به موتور گردش کار **Mastra Agent Workflow** و زیرسیستم نیتیو هوش مصنوعی مودل (`core_ai`).

---

## 🌟 ویژگی‌های کلیدی (Key Features)

1. **طراحی اختصاصی برای استاد (Teacher-First Workflow)**:
   - افزودن تب اختصاصی «آزمون‌ساز هوشمند» در نوار ناوبری درس (Secondary Navigation).
   - فرآیند ۴ مرحله‌ای شفاف، ساختاریافته و هدایت‌شده (Wizard).

2. **خواندن مستقیم منابع درسی (Direct Course Resource Ingestion)**:
   - اسکن خودکار فایل‌های درسی (PDF، اسلایدهای PPTX، جزوات DOCX، فایل‌های متنی) از طریق Moodle File Storage API (`mod_resource` و `mod_folder`).
   - استخراج‌کننده متنی مستقل در PHP بدون نیاز به ابزارها یا باینری‌های جانبی سرور (`text_extractor.php`).
   - امکان افزودن یادداشت‌ها و دستورالعمل‌های خاص تدریس توسط استاد.

3. **پشتیبانی کامل از ۶ نوع سوال استاندارد دانشگاهی**:
   - چندگزینه‌ای (Multiple Choice) با بازخورد تشریحی برای هر گزینه
   - صحیح / غلط (True/False) با توجیه علمی
   - کوتاه‌پاسخ (Short Answer) با کلمات کلیدی مجاز
   - تشریحی تحلیلی (Essay) همراه با سنجه تصحیح استاد (Rubric)
   - تطبیقی / وصل‌کردنی (Matching)
   - مرتب‌سازی ترتیبی (Ordering)

4. **پیش‌نمایش، ویرایش مستقیم و بازتولید تک‌سوال (Review & Re-prompting)**:
   - ویرایش درجا (Inline ContentEditable) متن صورت سوال و گزینه‌ها.
   - چت‌باکس اختصاصی برای هر سوال جهت صدور دستور بازتولید به هوش مصنوعی (مثلاً «گزینه‌ها را تحلیلی‌تر کن»).
   - حذف سوالات نامطلوب با محاسبه خودکار مجدد بارم‌ها.

5. **دروازه تأیید انسانی (Human-in-the-Loop Gate)**:
   - ثبت سازمان‌یافته سوالات در دسته‌بندی مشخص در **بانک سوالات مودل (Question Bank)**.
   - ساخت خودکار ماژول آزمون (`mod_quiz`) در صفحه درس با تنظیمات زمانی، تعداد تلاش و نمره‌دهی.
   - آزمون تنها پس از فشردن دکمه «تأیید نهایی استاد» ساخته و منتشر می‌شود.

6. **داشبورد مانیتورینگ، روان‌سنجی و بازخورد هوش مصنوعی (Analytics & Psychometrics)**:
   - کارت‌های شاخص‌های کلیدی: تعداد آزمون‌ها، پاسخ‌های دانشجویان، میانگین نمرات و شاخص کیفیت پذیرش هوش مصنوعی.
   - دسترسی تک‌کلیکه به گزارش‌های نیتیو مودل:
     - 🎯 **تحلیل روان‌سنجی سوالات (`report_statistics`)**: ضریب تمایز (Discrimination Index)، ضریب دشواری (Facility Index) و کارایی گزینه‌های انحرافی.
     - 👥 **پاسخ‌های تفصیلی (`report_responses`)**: تفکیک انتخاب‌های تک‌تک فراگیران.
     - 📊 **کارنامه کلی و نمرات (`report_overview`)**.
     - ✍️ **رابط تصحیح دستی سوالات تشریحی (`report_grading`)** بر اساس رابریک‌های هوش مصنوعی.

## ⚡ معماری موتور دوگانه (Dual-Engine Architecture)

این افزونه مجهز به سیستم پیشرفته Fallback است:
1. **موتور اصلی (Primary): Mastra Workflow Mode (`quiz-generation-v1`)**:
   - مبتنی بر گراف جهت‌دار بدون دور (DAG).
   - اجرای موازی تولید سوالات (`.parallel([generateMCQ, generateTrueFalse, generateEssay])`).
   - ماندگاری وضعیت در PostgreSQL و مکانیزم `step.suspend()` تا زمان تأیید استاد.
2. **موتور پشتیبان (Graceful Fallback): Moodle Native `core_ai`**:
   - در صورت در دسترس نبودن سرور مسترا، فرآیند فوراً و بدون وقفه از طریق هوش مصنوعی داخلی مودل پردازش می‌شود.

## 🚀 نحوه نصب و راه‌اندازی (Installation)

### ۱. نصب افزونه در مودل
پوشه افزونه را در مسیر `local/aiquizgen` مودل کلون یا مستقر نمایید:
```bash
git clone https://github.com/Rayesh-company/MOODEL-PLUGIN-.git public/local/aiquizgen
```

### ۲. ارتقای دیتابیس و پاکسازی کش
دستورات زیر را در ریشه مودل اجرا کنید:
```bash
php admin/cli/upgrade.php
php admin/cli/purge_caches.php
```

### ۳. تنظیمات مدیریت (Site Administration)
به مسیر زیر بروید:
> **مدیریت سایت** ← **پلاگین‌ها** ← **پلاگین‌های محلی** ← **آزمون‌ساز هوشمند**
- انتخاب موتور هوش مصنوعی (`mastra_hybrid` یا `moodle_ai`)
- آدرس اندپوینت سرور مسترا (پیش‌فرض: `http://localhost:3000/api/workflows/quiz-generation-workflow`)
- حداکثر سوالات قابل تولید

### ۴. استفاده در کلاس درس
با نام کاربری استاد وارد هر کلاسی شوید:
1. روی تب **«آزمون‌ساز هوشمند»** در نوار بالای درس کلیک کنید.
2. منابع را انتخاب و سطح دشواری را تنظیم نمایید.
3. سوالات تولیدشده را پیش‌نمایش و اصلاح کنید.
4. روی **«تأیید نهایی استاد و ساخت آزمون در مودل»** کلیک کنید.
5. پس از پاسخ‌دهی دانشجویان، از تب **«داشبورد و مانیتورینگ»** برای مشاهده تحلیل روان‌سنجی تک‌تک سوالات استفاده کنید.
